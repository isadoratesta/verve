# Verve — Landing Page Institucional

Landing page responsiva desenvolvida para a **Verve**, um serviço de atendimento inteligente para pequenos negócios via WhatsApp.

O projeto integra **design editorial**, **branding**, **copywriting**, **HTML5**, **CSS3 responsivo** e **SEO semântico** — construído do zero, sem frameworks.

> "Seu negócio merece estar presente mesmo quando você não pode estar."

---

## Sobre o projeto

A Verve é um serviço voltado para pequenos negócios que precisam manter presença no WhatsApp, responder clientes com agilidade e evitar perda de oportunidades por falta de disponibilidade.

A landing page foi criada para comunicar essa solução de forma sofisticada, clara e humana — evitando o tom genérico de "chatbot" ou "automação fria".

O foco foi construir uma experiência visual e textual que transmitisse confiança, sofisticação e clareza comercial.

---

## Tecnologias

- HTML5 semântico
- CSS3 (sem frameworks)
- Google Fonts — Cormorant Garamond + Inter
- SVG inline
- Media queries para responsividade completa
- JSON-LD para SEO estruturado
- Open Graph e Twitter Card

## Estrutura da página

| Seção | Descrição |
|---|---|
| Hero | Promessa principal, CTA e simulação visual de atendimento |
| Manifesto | Visão da marca sobre presença e oportunidade |
| Significado | Conceito por trás do nome Verve |
| Comparativo | Diferença entre operar com e sem o serviço |
| Como funciona | Fluxo do atendimento em 4 etapas |
| Fundadora | Seção institucional com narrativa e credibilidade |
| Demonstração | Espaço reservado para vídeo demonstrativo |
| Planos | Essencial R$297/mês · Crescimento R$597/mês |
| CTA final | Convite para agendar conversa pelo WhatsApp |
| Footer | Identidade, redes sociais, LGPD e informações legais |

---

## Responsividade

Ajustada para desktop, notebook, tablet e mobile, com refinamentos específicos para:

- quebra do título principal em telas menores
- proporção entre texto e elementos visuais
- espaçamento e tamanho de botões
- alinhamento e tamanho dos ícones sociais

---

## SEO e estrutura semântica

- `lang="pt-BR"`
- Título e meta description otimizados
- Open Graph e Twitter Card configurados
- JSON-LD estruturado
- Heading principal único
- Estrutura semântica com `header`, `main`, `section`, `article` e `footer`

---

## Principais decisões de UX/UI

- Layout limpo e editorial com contraste entre seções claras e escuras
- Tipografia com aparência premium via Cormorant Garamond
- CTA direto para WhatsApp sem fricção
- Card visual simulando conversa real de WhatsApp
- Navegação objetiva no desktop, adaptada para mobile
- Footer com informações legais completas (LGPD)
